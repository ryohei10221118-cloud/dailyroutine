# 🧴 保養提醒助手

智能保養流程提醒與管理 PWA 應用程式

## ✨ 功能特色

### 📱 核心功能
- ✅ **智能提醒系統** - 完全自定義的時段提醒，想設幾個就設幾個
- ✅ **完整保養流程** - 預設包含您的專屬一週保養計劃
- ✅ **產品管理** - 管理所有保養品，查看使用說明
- ✅ **使用記錄** - 追蹤保養習慣，統計完成率
- ✅ **離線可用** - 無需網路連線也能使用
- ✅ **推送通知** - 準時提醒您該保養了

### 🎯 預設流程
應用已預設您的完整一週保養計劃：

- **【A】一般日起床保養** - 茶樹 Pad + Ssuk Toner + 積雪草精華
- **【A★】水楊酸日** - 週一、週四使用水楊酸 Pad
- **【B】出門防曬** - 每天必備防曬步驟
- **【C】睡前保養** - 基礎夜間保養
- **【C+Mask】面膜日** - 亮白、鎮定、毛孔三種面膜輪替
- **【週日修護】** - 超溫和保養讓肌膚休息

## 🚀 安裝與使用

### 方式一：本地開啟（推薦測試用）

1. **準備圖標文件**（稍後說明）
2. **啟動本地伺服器**：
   ```bash
   # 使用 Python 3
   python3 -m http.server 8000

   # 或使用 Node.js
   npx http-server -p 8000
   ```

3. **在 iPhone 上訪問**：
   - 確保手機和電腦在同一 WiFi
   - 在 Safari 打開：`http://你的電腦IP:8000`
   - 例如：`http://192.168.1.100:8000`

4. **添加到主屏幕**：
   - 點擊分享按鈕 📤
   - 選擇「加入主畫面」
   - 完成！應用會像原生 app 一樣出現在主屏幕

### 方式二：部署到網路（推薦正式使用）

可以免費部署到以下平台：

#### GitHub Pages（最簡單）
1. 將代碼上傳到 GitHub
2. 在 Repository Settings → Pages 啟用
3. 訪問 `https://你的用戶名.github.io/倉庫名`

#### Netlify / Vercel（更專業）
1. 註冊帳號並連接 GitHub
2. 一鍵部署
3. 獲得 HTTPS 網址

**重要：** PWA 通知功能需要 HTTPS，所以建議部署到網路使用。

## 📖 使用說明

### 首次使用

1. **啟用通知**
   - 點擊底部「🔔 啟用通知」按鈕
   - 在彈出視窗中允許通知權限
   - iOS 16.4+ 需要將 PWA 添加到主屏幕後才能收到通知

2. **查看今日流程**
   - 首頁會自動顯示今天的保養計劃
   - 點擊任一時段查看詳細步驟
   - 勾選步驟進度，完成後點擊「完成此流程」

3. **自定義時段**
   - 切換到「時段設定」頁面
   - 點擊「+ 新增時段」
   - 設置時間、名稱、關聯流程和重複日期
   - 可以隨時編輯或刪除時段

4. **管理產品**
   - 在「產品管理」頁面查看所有保養品
   - 點擊產品查看使用說明
   - 可以新增自己的產品

5. **追蹤記錄**
   - 「使用記錄」頁面顯示歷史紀錄
   - 查看連續天數和完成率
   - 激勵自己養成保養習慣

### 進階使用

#### 調整時段時間
預設時段時間：
- 起床保養：20:30
- 出門防曬：07:30
- 睡前保養：22:00

**如何修改：**
1. 進入「時段設定」
2. 點擊時段卡片上的 ✏️ 編輯按鈕
3. 修改時間後保存

#### 增加額外時段
例如想在中午補擦防曬：
1. 點擊「+ 新增時段」
2. 設置時間為 12:00
3. 選擇流程「【B】出門前防曬」
4. 選擇重複日期（工作日）
5. 保存

#### 暫時跳過某個流程
- 不想在某天執行？直接不打開應用即可
- 或者在時段設定中暫時刪除該時段

## 🔔 通知說明

### iOS 通知要求
- **系統版本**：iOS 16.4 或更高
- **安裝方式**：必須「加入主畫面」
- **權限**：需要授予通知權限

### 通知時機
- 應用會在您設定的時間準時發送通知
- 通知會顯示流程名稱和內容
- 點擊通知可直接打開應用查看詳情

### 如果收不到通知？
1. 確認 iOS 版本 ≥ 16.4
2. 確認已將 PWA 添加到主屏幕
3. 檢查 iPhone 設定 → 通知 → 保養提醒助手
4. 確認允許通知權限
5. 嘗試重新安裝 PWA

## 💡 使用技巧

### 水楊酸日提醒
- 系統預設週一和週四為水楊酸日
- 今日流程會顯示「⭐ 水楊酸日」標記
- 記得等待 5-10 分鐘再進行下一步

- 週二：亮白面膜（Mediheal 玫瑰 / 黃色軟面膜）

- 水楊酸 Pad 和面膜步驟會顯示計時提醒

## 🛠 技術說明

### 技術棧
- **純前端技術**：HTML5 + CSS3 + JavaScript
- **PWA**：支援離線、推送通知、添加到主屏幕
- **本地存儲**：使用 localStorage 保存數據
- **無需後端**：所有數據存在您的設備上

### 瀏覽器支援
- ✅ Safari (iOS 16.4+)
- ✅ Chrome (Android & Desktop)
- ✅ Edge (Desktop)
- ⚠️ Firefox (部分功能受限)

### 數據安全
- 所有數據僅存儲在您的設備本地
- 不會上傳到任何伺服器
- 清除瀏覽器數據會清除應用數據
- 建議定期截圖備份重要設定

## 🔧 自定義開發

### 修改預設流程
編輯 `app.js` 中的 `createDefaultRoutines()` 方法：

```javascript
this.routines = {
    'routine-custom': {
        id: 'routine-custom',
        name: '我的自定義流程',
        type: 'custom',
        steps: [
            {
                text: '步驟描述',
                notes: '注意事項',
                product: 'product-id',
                timer: 300, // 秒數
                optional: false
            }
            // ... 更多步驟
        ]
    }
};
```

### 添加新產品
編輯 `app.js` 中的 `createDefaultProducts()` 方法。

### 修改樣式
編輯 `styles.css` 自定義顏色和佈局：

```css
:root {
    --primary-color: #4CAF50; /* 主色調 */
    --secondary-color: #2196F3; /* 次要色 */
    /* ... 其他變數 */
}
```

## 🐛 常見問題

**Q: 可以在 Android 上使用嗎？**
A: 可以！Android 的 Chrome 對 PWA 支援更好，通知功能更穩定。

**Q: 數據會同步到其他設備嗎？**
A: 目前不會，數據僅存在本地。未來可以考慮添加雲端同步功能。

**Q: 可以匯出數據嗎？**
A: 目前沒有匯出功能，但數據存在 localStorage 中，可以通過瀏覽器開發者工具查看。

**Q: 如何重置應用？**
A: 在瀏覽器中清除網站數據，或在應用設定中清除緩存。

**Q: 可以設置提前提醒嗎？**
A: 目前不支援，但可以手動創建一個提前 10 分鐘的時段。
